# Add your real 3D saloon models here

This starter pack contains the visual reference assets generated in ChatGPT. It does **not** contain your Meshy/Blender FBX or GLB model files because those files were not uploaded in this conversation.

Recommended filenames:

- `SM_SaloonShell.fbx` or `.glb`
- `SM_Bar.fbx`
- `SM_Entrance.fbx`
- `SM_PokerGreen.fbx`
- `SM_PokerRed.fbx`
- `SM_Roulette.fbx`
- `SM_SlotArea.fbx`
- `SM_CentralLounge.fbx`
- `SM_DuelArena.fbx`
- `SM_Gallows.fbx`
- `SM_Props_*.fbx`

Keep major gameplay stations as separate models/prefabs. Do not merge the whole saloon into one mesh.
